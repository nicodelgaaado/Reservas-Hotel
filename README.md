# Reservas-Hotel

Sistema de reservas hoteleras desarrollado en Java como ejercicio de Programación Orientada a Objetos.

## Incluye

- Gestión de clientes, reservas y habitaciones.
- Patrones Builder, Factory Method, Singleton, Adapter y Decorator.
- Facturación electrónica simulada y notificaciones multicanal.

## Ejecución

Compilar y ejecutar la clase principal:

```bash
mvn compile exec:java
```

La aplicación muestra un escenario de reserva, cálculo de recargos, generación de folio, facturación y notificaciones.
